### Install

<details>
<summary><strong>Phone & tablet</strong></summary>

Tap your link → Allow → Open → Install. No extra steps.

</details>

<details>
<summary><strong>Android TV / Firestick</strong></summary>

1. Enable *Apps from Unknown Sources* (Settings → Device → Developer Options)
2. Install **Downloader** (AFTVnews) from Store
3. Paste the link → Download → Install → open with remote (arrows + OK)

</details>
